KUBERNETES EXERCISE 1 - HELLO POD
=================================

Objective:
---------
Deploy an Nginx container as a Kubernetes Pod using Minikube and Docker Desktop, expose it using a NodePort Service, and access the application through a browser.


1. Check Chocolatey Installation
--------------------------------
Command:
choco --version

Purpose:
Verified that Chocolatey package manager was successfully installed and available in PowerShell.


2. Install Minikube
-------------------
Command:
choco install minikube -y

Purpose:
Installed Minikube on Windows using Chocolatey. Minikube is used to create and run a local Kubernetes cluster.


3. Verify Minikube Installation
-------------------------------
Command:
minikube version

Purpose:
Verified that Minikube was installed correctly and checked the installed version.


4. Verify Docker Installation
-----------------------------
Command:
docker --version

Purpose:
Verified that Docker was installed and available. Docker Desktop is used as the container runtime/driver for Minikube.


5. Start the Kubernetes Cluster
-------------------------------
Command:
minikube start --driver=docker

Purpose:
Started a local Kubernetes cluster using Minikube with Docker as the driver.


6. Check Minikube Cluster Status
--------------------------------
Command:
minikube status

Purpose:
Verified the status of the Minikube cluster and its Kubernetes components after starting the cluster.


7. Check Kubernetes Nodes
-------------------------
Command:
kubectl get nodes

Purpose:
Verified that the Kubernetes node was available and in the Ready state.


8. Create the Nginx Pod
-----------------------
Command:
kubectl run hello-k8s --image=nginx --port=80

Purpose:
Created a Kubernetes Pod named "hello-k8s" using the official Nginx container image.
Port 80 was specified for the Nginx application.


9. Verify Pod Status
--------------------
Command:
kubectl get pods

Purpose:
Checked whether the hello-k8s Pod was successfully created and running.


10. Expose the Pod as a Service
-------------------------------
Command:
kubectl expose pod hello-k8s --type=NodePort --port=80

Purpose:
Created a NodePort Service to expose the Nginx Pod outside the Kubernetes cluster.


11. Verify the Service
----------------------
Command:
kubectl get services

Purpose:
Verified that the hello-k8s Service was successfully created and obtained its service details and exposed port.


12. Access the Application
--------------------------
Command:
minikube service hello-k8s

Purpose:
Opened the hello-k8s Service through Minikube and accessed the Nginx application in a web browser.


Final Result:
-------------
Successfully deployed the Nginx container as a Kubernetes Pod using Minikube.
The Pod was verified using kubectl, exposed through a NodePort Service, and accessed through the Minikube service.

Technologies Used:
------------------
- Kubernetes
- Minikube
- Docker Desktop
- kubectl
- Nginx
- Chocolatey
- Windows PowerShell
